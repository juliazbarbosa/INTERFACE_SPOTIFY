# 🎵 Interface Spotify

>  interface inicial do Spotify desenvolvido com HTML, CSS, JavaScript e JSON, recriando o layout da plataforma  com foco em responsividade e manipulação dinâmica de dados.

## Demonstração

![Preview do Projeto](.preview.png)

🔗 **Deploy ao vivo:** https://juliazbarbosa.github.io/INTERFACE_SPOTIFY

## Funcionalidades

- Interface inspirada na página inicial do Spotify.
- Barra de pesquisa.
- Menu lateral de navegação.
- Exibição dinâmica das categorias musicais.
- Carregamento das informações por meio de arquivo JSON.
- Layout responsivo para diferentes tamanhos de tela.

## Aprendizados e desafios

Durante o desenvolvimento do projeto pude por em prática conceitos de Estruturação de páginas com HTML, organização e estilização de layout com CSS, uso de Flexbox e Grid para posicionamento dos elementos, realizei a manipulação do DOM com JavaScript. O maior desafio durante o processo foi manter uma aparência fiel á original mantendo a organização e responsividade do código e a introdução do JavaScript para carregar os dados de forma dinâmica.
